Пока без базы данных: все данные хранятся в памяти (`Models.cs → SampleData`) и сбрасываются при перезапуске.

## Функции

**Преподаватель**
- видит только свои дисциплины и группы, в которых их ведёт;
- выставляет оценку (2–5, тип работы, дата): пустой выбор в таблице и кнопка «Сохранить» добавляют новую оценку;
- изменяет оценку: выбрать строку в таблице, поправить и сохранить;
- удаляет оценку: выбрать строку, очистить поле «Оценка» и сохранить;
- просматривает все оценки выбранного студента и всех студентов выбранной группы;
- на вкладке «Удалённые оценки» видит удалённые записи и восстанавливает их.

**Студент**
- видит только свои оценки, может отфильтровать их по дисциплине и посмотреть средний балл.

## Мягкое удаление

Оценка не стирается: у неё ставится `IsDeleted = true` и время удаления `DeletedAt`.
Удалённые оценки не показываются в обычных списках, но доступны для просмотра и восстановления.
